
# 🏓 Ping Pong by Aamen

A simple **Ping Pong Game** built using **Python** and the **Turtle Graphics** library.
This project is a fun and interactive way to explore 2D graphics, animation, and event handling in Python.

---

## 🎮 Game Overview

Two players compete to keep the ball in play.
Each player controls a paddle to bounce the ball — if a player misses, the opponent scores a point!

* Player 1 controls: **W** (up) / **S** (down)
* Player 2 controls: **Arrow Up** / **Arrow Down**
* The score is displayed at the top of the screen and updates in real-time.

---

## 🧠 Features

✅ Two-player controls
✅ Real-time ball movement
✅ Collision detection between ball and paddles
✅ Dynamic score tracking
✅ Simple and clean code using functions and loops

---

## 🧩 What I Learned

* Using **Turtle Graphics** for 2D game design
* Handling real-time animations with `while True` loops
* Managing keyboard events with `onkeypress()`
* Writing clean, modular, and reusable code

## 🚀 How to Run the Game

1. Make sure you have **Python 3.x** installed.

2. Clone this repository:

   ```bash
   git clone https://github.com/Aamen2006/pingbong_by_aamen
   ```

3. Navigate to the project folder:

   ```bash
   cd pingbong_by_aamen
   ```

4. Run the Python file:

   ```bash
   python "ping bong by aamen .py"
   ```

Enjoy the game! 🕹️
